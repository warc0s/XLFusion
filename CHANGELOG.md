## [2.4.1] - 2026-06-06

### Added

- MIT license and package license metadata.
- Python packaging metadata for editable installs and console script usage.
- GitHub Actions CI for Python 3.10 and 3.11.
- Issue templates, pull request template, contribution guide, security policy, code of conduct, maintainer guide, changelog, and release notes.
- OSS-safe batch, algebra, and metadata recovery examples without binary model files.

### Changed

- Clarified installation, project status, testing, artifact policy, and release workflow documentation.
